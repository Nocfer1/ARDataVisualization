# AR Mobile Project for XRD

A mobile augmented-reality application project for exploring 3D visualizations of Transient Electromagnetic (TEM) data in the physical environment. The goal is to make subsurface resistivity models easier to inspect and discuss by letting users place, view, and manipulate a clear 3D representation through a phone or tablet.

The project is being developed in Unity and is intended to support Android and iOS. The experience should focus on the data and a small set of useful controls: no decorative effects are needed unless they improve understanding of the visualization.
